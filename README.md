# ✦ Unique Local AI

Unique is a lightweight offline AI assistant designed for Termux on Android.

## Features

- Fully local AI
- Qwen2.5-1.5B
- GGUF Q4_K_M
- llama.cpp backend
- Claude-Code-inspired terminal UI
- Streaming responses
- Conversation memory
- No web UI
- No cloud API required
- One-command launcher

## Requirements

- Android
- Termux
- Around 2 GB+ free storage
- Sufficient RAM for the model
